## Achados de infraestrutura

- `api.bcb.gov.br` não resolve DNS a partir do GitHub Actions; `www3.bcb.gov.br` (SOAP), `dadosabertos.bcb.gov.br` e `olinda.bcb.gov.br` funcionam. **Impacto na Fase 1:** o adapter do SGS precisa de caminho alternativo à API REST. Investigar antes de escrever o adapter.
- A busca do portal de dados abertos às vezes devolve "Requisição Inválida" (HTML); o SOAP cobre essas falhas.
