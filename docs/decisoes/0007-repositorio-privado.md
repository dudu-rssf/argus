# 0007 — Repositório privado

**Status:** aceita · 2026-10-04

## Decisão
`dudu-rssf/argus` é privado.

## Motivo
O GitHub desativa workflows agendados de repositórios públicos após 60 dias sem commits, o que parou a coleta da primeira tentativa. Privado também evita exposição acidental de configuração.

## Consequências
- Repositórios privados no plano grátis do GitHub têm cota mensal de minutos de Actions. Uma coleta diária de poucos minutos fica bem abaixo dela; conferir o consumo na Fase 1.
